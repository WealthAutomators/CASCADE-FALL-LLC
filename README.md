## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui (Radix primitives)
- Lucide Icons
- Framer Motion
- Embla Carousel
- React Context (cart, wishlist, recently viewed)
- localStorage persistence (no backend)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
```

Checkout remains a demonstration flow. Use coupon code `SAVE10` on the cart page for a 10% discount.
